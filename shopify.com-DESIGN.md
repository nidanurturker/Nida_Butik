# Shopify Style Design Guide

This project uses a clean, editorial, Shopify-inspired boutique layout.

## Visual Direction

- Use a light neutral base with black text and subtle beige or sand accents.
- Keep spacing generous and the layout airy.
- Prefer large typography for hero text and restrained uppercase labels for navigation and metadata.
- Make product cards feel premium, minimal, and fashion-focused rather than tech-focused.

## Layout Rules

- The header stays fixed and compact.
- The hero section uses a split visual composition with large imagery and a short editorial message.
- The collection section uses a clear heading, product filters, and a dense responsive grid.
- The shopping cart opens as a right-side panel.
- Mobile views should collapse cleanly into one-column or two-column layouts without breaking hierarchy.

## Typography

- Headlines should be bold, wide, and simple.
- Body copy should stay short and readable.
- Use uppercase for labels, buttons, and small navigation elements.

## Components

- Product cards should show image, title, category or material, price, and a single add button.
- Images should be large enough to make the page feel visual and commercial.
- Buttons should be minimal and high contrast.
- The page should feel like a premium fashion storefront, not an admin dashboard.

## Interaction

- Keep hover effects subtle.
- Use smooth transitions for product images and cart panel behavior.
- Make the page feel polished but not over-animated.
